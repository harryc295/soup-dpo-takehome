# DPO with layer streaming on a T4: did it train, and should it ship?

Take-home for Soup's AI Engineer internship. The report is **[REPORT.md](REPORT.md)**
(verdict and evidence, 2 pages). Everything below shows how to reproduce it.

## Run it

Open `run_colab.ipynb` in Colab, pick a **T4**, then Run all (about an hour). It clones this
repo, installs `soup-cli[train]==0.75.1`, and writes every log with timestamps to
`results/`. The T4 results in this repo came from that notebook, unedited.

## What's here

| File | Part | What it does |
|---|---|---|
| `prepare_data.py` | data | 500 pairs from `argilla/distilabel-intel-orca-dpo-pairs` (Soup's Russian package wasn't needed, per the email). Keeps the raw 500 for linting, drops ties, splits 400 train / 100 held-out, and builds a length-balanced control set |
| `soup.yaml` | run | DPO + `stream_layers` on Qwen2.5-0.5B-Instruct, fp16 on T4 |
| `soup_lenbal.yaml` | control | Same config on the length-balanced set |
| `memory_budget.py` | 1 | VRAM estimate from the model config, before training, then compared with Soup's logged peak and `nvidia-smi` |
| `verify_training.py` | 2 | Checks the adapter saved on disk actually learned the preference: weight checks, implicit reward margin on train and held-out pairs, compared with a zero adapter and a random adapter of the same norm |
| `silent_checks.py` | 3 | Truncation, length bias, NaN / skipped fp16 steps, likelihood displacement, what Soup's run DB drops, Cyrillic token cost |
| `make_ship_inputs.py` | 3 | Task-eval file plus two fake adapters (zero, random) to see if `soup ship` can tell them apart from a real one |
| `run_colab.ipynb` | all | Runs everything on a T4 and collects the evidence (generated by `build_notebook.py`) |
| `results/` | evidence | Raw T4 logs, `nvidia-smi` samples, JSON outputs, the trained adapter |
| `rehearsal/` | evidence | The same pipeline run first on an RTX 4060 Ti (8 GB, bf16), used to debug before the T4 run and to calibrate the memory model |
| `soup-patches/` | 4 | Fixes to Soup for the problems found |

## Local run

```bash
python -m venv .venv && .venv/Scripts/pip install torch --index-url https://download.pytorch.org/whl/cu128
.venv/Scripts/pip install "soup-cli[train]==0.75.1"
python prepare_data.py
SOUP_DB_PATH=$PWD/soup.db soup train --config soup.yaml -y
python verify_training.py --adapter out-dpo
python silent_checks.py --run out-dpo --db soup.db
```
